      Two ways to show it in Power BI
      
          
      
            Recommended
            
      Image visual: any size, reads like a card
      
            
      1. Create the measure and set its Data category to Image URL.
      2. Select Insert › Image and place it on the page.
      3. In Format › Image, set Image URL with fx › Field value and pick your measure.
      4. Resize the visual freely. Slicers and filters on the page change the card.

      Questions
      
            
      Do I need a custom visual?
      No. The measure returns an SVG image as text. Power BI's built-in Image visual, Table, Matrix and some card visuals can show it once the measure's Data category is set to Image URL.
      
            
      Is my data uploaded?
      No. You type measure names and test values in the browser. The tool never connects to your model, and your design is saved only in this browser unless you share a link.
      
            
      Why does my sparkline show a single dot?
      The date column in Card settings must be the date table that actually filters your measure. If it points to a different calendar, only one period returns a value.
      
            
      Can I change the design later?
      Yes. Use Export to save the design as a file, or Share link, then open it again and copy the updated DAX.
