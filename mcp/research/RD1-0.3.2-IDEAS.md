## B-275: a reversed table's columns end at the box's right edge
Notes: [rd1/b275/NOTES.md](rd1/b275/NOTES.md). Cause: `keepView` (`mcp/lib/twin-pages.mjs:222`, `:228`) handles a
table only when every column has a width; the tables people make have none, so Power BI lays them from the left.
Measured (7 candidate visual.json files, Microsoft's validator 0.5.0): 0 errors, 0 warnings each once `.platform`
is present; a made-up enum value gives `PBIR_FORMATTING_ENUM_INVALID` (the validator reads `columnHeaders`); a
`columnWidth` naming a field not in the visual gives 0 (the builder's tests must check selectors). Header widths:
Arabic 269 vs English 247 (+9%); in an 800-wide box 498 empty at the right in Arabic. Grow to fit fills it with no
width computed and no data read. Precedents: `assets/js/pbip-page.js:884-886`, the twin's heatmap
(`assets/js/report-mirror.js:670`). The risk: the O-14 rule (grow to fit, no word wrap, a long text column pushes the
others out); Desktop check 4 decides between exempting the twin or adding values word wrap.

## B-278: the app's own prompt first, the browser page as the named fallback
Notes: [rd1/b278/NOTES.md](rd1/b278/NOTES.md). Today the app's prompt is asked when the app declares form elicitation
(`mcp/tools/approve_plan.mjs:29`), else the browser page. The gap: an unanswered prompt (`:38`) throws after 10
minutes and never opens the page. Measured with the pinned SDK 1.32.2 in one process: accept, decline, cancel come
back right; `elicitation: {}` is seen as `{"form":{}}`; no capability gives "Client does not support form
elicitation." (no code); a wrong type gives -32602; declared but never answered gives -32001 at the timeout; accept
round trip median 0.21 ms over 200 runs. Recommended C + A: the words, then fall back to the page on a timeout or an
error, a 45 s wait, and a setting that forces the page. Not URL mode (it would send the page's one-time link through
the app). No typed-back code. The words say plainly that neither the app's prompt nor the browser page can tell the
person's click from one made by an AI or a program that controls the screen, mouse or browser (drafts in the notes,
English and Arabic).
