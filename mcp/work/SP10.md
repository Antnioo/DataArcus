## The interface (DAMirrorPolicy, frozen; every function pure: a visual's JSON and the model's facts in, a named answer out)
- Readers (one copy, report-mirror.js takes them from here): isObj, lit, strOf, entries, projections, first.
- Families: COLUMN, BAR, WATERFALL, SLICER, SIDELESS (frozen lists); isCustom(type); kindOf(json) -> 'column' | 'bar'
  | 'waterfall' | 'table' | 'matrix' | 'newCard' | 'textbox' | 'button' | 'navigator' | 'slicer' | 'plain' | 'other'
  | 'custom' | 'group' | 'unreadable'. Requires visual-types.js only (isCustom); nothing else.
- Time: TIME_NAME, DATE_LIKE; isTime(field, dateTables); categoryIsTime(visual, dateTables) (its first Category
  field); invertsTimeAxis(visual, { dateColumns, dateTables, textColumns, timeRightToLeft }) (a continuous time axis
  the twin inverts: chartRtl writes categoryAxis.invertAxis on its yes).
- Content direction: MOVES_ONLY, movesOnly(kind) (custom, group, unreadable: place and shadow only);
  waterfallKind(visual, { mode, timeRightToLeft, dateTables }) -> 'waterfallNative' | 'waterfallTime' | 'waterfall'
  (mode: visual-gallery.js waterfallRtlOf's answer, resolved by report-mirror.js, so the policy needs no gallery);
  ONE_ROW_H, oneRowButtons(visual, height) (a button slicer on one row: its buttons read from the right);
  verticalValues(visual) (a new card's values down keep their order); TITLED, titled(kind) (the title set right even
  when the visual has none); keepsGridLtr(json) (a table or matrix keeps left to right inside: B-284's home).
