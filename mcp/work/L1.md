# L1: smooth line charts as the default look, with a marker on each point (19 Oct, cloud builder)

Branch `feat/0.3.0-smooth-lines` from `origin/integration/0.3.0-wave` 7dfb9d4 (the routine "L1 resume" of 19 Oct
22:37 UTC moved the base there from release/0.3.0). Push the branch only; no PR, no merge. Not edited here:
mcp/CHANGELOG.md, mcp/WORK.md (parallel builders).

## CHANGELOG line
- L1: line charts (and the line of a combo) are smooth by default, monotone (no swing past the data), with a small filled
  dot in the series' colour on each point so every value stays findable; `smoothLines: false` keeps straight lines without
  dots. plan_layout pins it, the approval page's preview draws the curve and its dots, the look summary says it.

## What is there (7dfb9d4)
- `assets/js/pbip-page.js` (shared with the website): a line chart's `lineStyles` = strokeWidth 3; with `o.smoothLines`
  also lineChartType 'smooth' + interpolationSmooth 'monotoneX'. Default straight.
- `assets/js/visual-gallery.js` (D2's combo): `lineStyles` strokeWidth 3 only; `WRITES` lists strokeWidth.
- `mcp/server.mjs`: smoothLines in CREATE_REPORT_INPUTS (Default false), REPORT_LOOK (pinned, B-114 / A-02),
  LOOK_DEFAULTS false; plan_layout takes every REPORT_LOOK input; reportLook = lookOf(withLookDefaults(a)).
- `mcp/lib/approval-window.mjs`: look summary row "Smooth lines" (true/false as a value).
- `assets/js/page-preview.js`: a line chart is a grey polyline whatever the file says.
- Microsoft's capabilities data (`@microsoft/powerbi-core-visual-schema`, the version mcp/package.json pins), `lineStyles`
  of lineChart and both combos: showMarker, markerShape (circle...), markerSize, markerColor, lineChartType, interpolationSmooth
  (monotoneX, cardinal). Desktop lab 7 Oct ("GX try"): lineStyles with showMarker and lineChartType 'smooth' in ONE
  entry with NO selector drew "a smooth line, a dot per month" and was kept on Save.
