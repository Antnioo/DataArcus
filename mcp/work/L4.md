## Decisions I made
- **Option**: `flipCards: true | [1..6]` (card numbers in reading order, the same cards on every page); left out or
  `false`: off, the files byte-for-byte as before. In `REPORT_LOOK` (pinned, filled from the plan; another value at
  create_report refused, nothing written) and `LOOK_DEFAULTS` (`false`). A number past the cards built is told
  (`flipCards.notFlipped`), never an error.
- **Built as one small MCP helper** (`mcp/lib/flip-cards.mjs`) that turns the writer's KPI card files into the flip
  set after `Pbip.build` (plan build and write alike, so the J14 artifact holds it): the website's shared writer is not
  changed. The front keeps the card's visual name, position, tabOrder and group; the back (`isHidden`, tabOrder front+1)
  and the backdrop (no tabOrder, decorative) are new, in the same group and box.
- **The model is never changed**: the 3 measures a card (front, back, backdrop; each `dataCategory: ImageUrl`, display
  folder "DataArcus flip cards", in the KPI measure's own table) go into ONE script file "<model> - flip cards.tmdl"
  (`createOrReplace` + `ref table`, Fix.measure, as the format script), written with the report after go, by the same
  `writeScript` (free name, never over a file). A name the model already has is never taken (" 2", " 3"...). One helper
  (`flipScript`) so L3's metric-switcher script merges into it when L3 lands.
- **Before the script is applied**: the plan and the approval page say "apply the script first"; plan_layout's exact
  check counts the script's measures as present (they are written with the report); check_report on the written report
  says it as a note (`IMAGE_MEASURE_PENDING`, "a DataArcus rule"), never "can break".
- **The front**: the card's own title (the plan's display name, Arabic in an Arabic report) and the value by DAX:
  percent formats `0.0%`, a whole-number format `#,0`, otherwise automatic K/M/B with 2 decimals (the KPI rule's
  shape); blank shows "--". Sizes from the card being replaced (its title and value pt), the design's font and colours.
- **The back, one line, metadata only**: the measure's name (bold) and one line: its description from the model when
  it has one (control characters dropped, instruction-like text dropped, 90 characters at most, XML-escaped), its value
  in the model's own format string (FORMAT), and year on year only when the KPI's bound date is the key column of a
  table marked as a date table (`dataCategory Time`, `isKey`), written `CALCULATE([m], SAMEPERIODLASTYEAR(date))` inside
  IF(ISBLANK) guards; otherwise left out and told why. The MCP never returns a value or the description's text: the
  answer and the approval page name what the back holds.
- **Encoding**: the static HTML is URL-encoded for every `%`, `#`, `"` and non-ASCII character; the DAX value is
  XML-escaped then `%` -> `%25`, `#` -> `%23` with SUBSTITUTE. Single quotes in the HTML; no double quote reaches DAX.
- **Arabic**: `dir="rtl"`, text aligned right, the turn mirrored (front from 25deg, back from -25deg: the reading
  direction turns, so does the card); the back's words in Arabic. The separate twin mirrors the three visuals like any
  visual (same box, mirrored) and keeps visual and bookmark names; its faces keep the English report's measures (the
  script is the model's), told in the answer. The EN-AR copy (X1) renames visuals and copies the bookmarks per page set
  by its own code; checked here.
- **Phone**: the three visuals stacked in the card's phone box (as on the page), so the card turns on the phone too;
  PHONE_OVERLAP knows a flip set (image visuals of one box whose faces link bookmarks of each other) and does not flag it.
- **Alt text** on both faces ("<title>, KPI card: select to see what it means" / "<title>: what it means; select to
  turn back"), the backdrop's empty (decorative); the faces' container background, border and shadow off (the backdrop
  is the panel, the theme draws it), titles off, `image.fit` "Fit" (measured for the logo).
- **check_report**: `BOOKMARK_VISUAL_MISSING` (error): a bookmark whose targetVisualNames or explorationState names a
  visual its page does not have; `IMAGE_MEASURE_PENDING` (note); PHONE_OVERLAP skips a flip set.
