  disclosure in plain text (no HTML, no HTTP); approve_plan.mjs still takes them from approval-window.mjs (re-exported).

  gain `export`, and the window imports them. The disclosure never imports the window (no cycle).
- PREVIEW_PAGES_MAX stays in the window: it decides how many pictures the view draws.
- The suite reads each page from the real server (the link the server opened, logged by the tests' browser) rather
  than calling approvalHtml, so the path a person's browser takes is the one recorded; the prompts come from a second
  server whose client declares elicitation and closes each prompt (nothing refused, nothing written).
- The records are sha256 and length (pages up to 100 KB with their preview pictures); SP23_DUMP=<folder> writes them.
- Four guards read approval-window.mjs's source as text; the text they look for moved, so each now reads both files:
  0.3.0-claims (A2-A2 the WCAG credit; the banned-words and claims lists), release-text (its claims list), fx3 (C2
