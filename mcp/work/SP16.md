  &) it follows the evaluator, said in the file. It is a check between two readers, not Desktop.

  svg-escape and svg-expressions keep `20261103sp12` (unchanged files).

## For the owner
- E1 found 3 disagreements on the base, recorded and not fixed (none reachable from a design the compiler builds):
  (1) `x / 0` with a literal 0: the evaluator throws DIV0, DAX gives Infinity (the compiler only divides by 1000 and
  1,000,000; ratios use DIVIDE); (2) FORMAT of a number of 1e21 or more: the evaluator's roundDecimal uses toFixed,
  which writes 2.5e+21, so the preview prints "3" where DAX prints 2,500,000,000,000,000,000,000 (and "6.03" for
  6.02e23 with "0.00"); (3) FORMAT ( -0.004, "#,0.0" ) is "0.0" in the evaluator and "-0.0" in the reader (the
  compiler's own formats make a number that rounds to zero exactly 0 first, so it never meets this; Desktop would
  settle which "-0.0" DAX writes).
