## CHANGELOG line
- **A model file that can't be read is said, not skipped:** when a TMDL file of your project is empty, cut short,
  not text, badly indented or holds git merge-conflict markers, read_model and the Model Health Check name the file
  and why first, give no score (a score of the part read would be wrong), and DataArcus won't plan a report, a twin or
  a calendar on that model until the file is fixed.

## Decisions I made
1. **Any definition file**, not only a table's, withholds the score and refuses planning: a broken `relationships.tmdl`
  or `model.tmdl` changes the score as much.
2. **Answer key `unreadable`** (`{ message, skipped: [{ file, why }] }`): check_model_health already has a `skipped` key
  (checks without column types), so the list sits inside it; the reader's own field is `skipped`, as in the brief.
3. **"Cut short" only on evidence** (the reviewer, 26 Oct, replacing my first rule "no final line break" that refused
  whole files hand-edited in VS Code, Notepad or git tools): no final line break AND a visibly incomplete last item: a
  bare word that is no TMDL flag, a property with no value, a data type that is none, a `[column]` or `"text"` or
  bracket never closed, a declaration with no name or an open `'quoted name'`, a description with no object. An open
  ``` block is "parse stopped" in any file. A cut exactly at a line break, or one that ends on a whole item (a known
  flag, a whole value), reads as a whole, shorter file (Seen 1).
4. **check_model_health on such a model:** no fix scripts and no plan (a script built from part of a model could miss a
  name), a planId refused; the findings partial, with counts. add_gulf_calendar refuses too (it plans a write).
5. **The mutant is in the new suite** (a copy of tmdl-model.js with `skipped` emptied, run through the same checks), not
  in `test-0.3.1-mutation.mjs` (SQ11's tests); the reviewer can add the row there.
6. **The website's analytics event** carries nothing new (17 Oct rule: nothing about the model is sent).
7. **The theme generator's** `tmdl-model.min.js` stamp moved too (the stamp check asks it), so its `.min.js` was rebuilt.

## Seen, not in scope
