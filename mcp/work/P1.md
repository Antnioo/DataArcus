## Decisions I made
- The CHANGELOG check counts the section's non-empty lines (a wrapped entry is 2), and only [Unreleased]: older
  versions keep their codes as history.
- "the owner / laptop / reviewer" is caught only as those words (not "laptop-friendly", not "an owner's"); `R\d+` and
  `J\d+` only as whole words (R1C1 and R² pass).
- No Unicode normalisation in the path code: the file system decides (see Results); the test checks both answers.
- The long path is over 300 characters under the temp folder; Windows passed it (Node's long-path handling), so no
  subset and no skip.
- macOS runs the whole suite in the same 5 shards; `mcp-macos` adds them up like `mcp`, not a required check until the
  owner makes it one.
- No packaging smoke on macOS: the workflow runs none (packaging lives in the engine).
- The CHANGELOG line is here only: the reviewer puts it into `mcp/CHANGELOG.md` when merging (three builders at once).
- A CI run by hand on my branch (the "Run workflow" route in mcp/CLAUDE.md) to measure macOS before reporting.
