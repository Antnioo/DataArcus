## The interfaces (D-1103-11: one input, one output, no hidden state)
- `visual-capabilities.mjs`: `fitsCapabilities(visualType, { Role: [field] }) -> { ok, problems }`, `capsOf(type)`,
  `drillsIn(type)`, `roleLabel(type, role)`, and the field helpers `isValue`, `isCol`, `copy`. Its one state is the
  validator's metadata provider, loaded once at import by a top-level await (read-only; null when the package can't load).
- `visual-candidates.mjs`: `rankCandidates(meaning, visual, opts) -> { candidates, best, other, closer, calendarNote,
  form, guess, confidence, idKnown, rolesRead }`; also `candidatesOf(meaning)`, `formOf(type)`, `NATIVE`, `CHARTS`,
  `FORMS`. The meaning goes in whole (its confidence, idFit, named, targets): the choice's confidence is high only with
  the package's roles read AND an id that names the kind written; no fitting candidate gives no native (the person
  decides). Pure.
- `replacement-disclosure.mjs`: `disclose(meaning, visual, opts, rank) -> nativeFor's answer for a custom visual`,
  `detailsOf(option, { meaning, visual, opts, form, calendarNote }) -> { lost, format, expand, needs, tooltips }`,
  `replacementLine(entry)`, `ownSettingsSaid(o)`, `shortType(type)`, `aOr`, `nOf`, `LABEL`, `CONFIDENCE_LEVELS`,
  `AZURE_NEEDS`. Pure apart from reading pbip-sizing.js's measured heights at load. It writes nothing: the plan lists
  the entry and the person approves it in DataArcus's own window first.
- `visual-meaning.mjs`: `nativeFor(visual, opts) = disclose(m, visual, opts, rankCandidates(m, visual, opts))` with
  `m = meaningOf(visual, opts)`; the rest as before.

## Decisions I made
- The field helpers isValue, isCol and copy live in visual-capabilities.mjs (one place, D-1016-01); visual-meaning.mjs
  and visual-candidates.mjs import them. SP18's lesson offered "a tiny module or a copy": a copy is two places.
- The closer-native and second-option choice (bullet, calendar, map, text search) and the choice's confidence are
  visual-candidates.mjs's: they reorder the candidates. The confidence's evidence sentence is replacement-disclosure.mjs's
  (words); rankCandidates returns the facts it is written from (guess, idKnown, rolesRead).
- replacementsOf and axesFor stay in visual-meaning.mjs: they are the orchestration over the inventory (one entry per
  custom visual, the axis decision); replacementLine and shortType (the plan's words) move to the disclosure.
- `n` (a count with its word) moves to the disclosure as `nOf`; meaningOf imports it as `n` so its text is unchanged.
- SZ (pbip-sizing.js) and DROPDOWN_FLOOR move with detailsOf, their only reader.
- test-0.3.1-write-gate.mjs:177: a comment named visual-meaning.mjs as the module that loads the validator's metadata
  provider; it now names visual-capabilities.mjs (a comment; no check or number changed).
