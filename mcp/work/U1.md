## CHANGELOG line
- U1: Microsoft's October 2026 update (Desktop 2.159.883.0): Microsoft's visual catalog 0.1.3 (19 Oct) now lists the
  dropdown slicer's rounded box, so the validator checks it instead of DataArcus marking it "known"; check_report's
  bundled schemas follow Microsoft's September (SU09) release (visualContainer 2.13.0, the version Desktop saves); the
  list slicer's new dropdown mode is researched and not written yet (preview, not measured in Desktop).

## What Microsoft published (details and quotes: `mcp/research/POWERBI-2026-10.md`)
- Power BI Desktop 2.159.883.0, published 15 Oct 2026 (Microsoft Download Center, id 58494).
- The October 2026 Feature Summary (Fabric community blog): list slicer dropdown mode (preview), native Gantt (preview),
  chart plot area background colour, auto-expand hierarchy axes, personal bookmarks keep column widths, Report Authoring
  skill and custom visuals.
- `@microsoft/powerbi-core-visual-schema` 0.1.3 (npm, 19 Oct 2026; DataArcus pins 0.1.1). Microsoft's validator reads
  it (its dependency is `>=0.1.0 <1.0.0`; the lock holds 0.1.1). Of what DataArcus writes: `slicer` gains the
  `dropdown` object (`borderRadius`, `borderIndividualCorners`, `borderColor`, the three DataArcus writes, and more);
  `listSlicer` gains `data.dropdownMode` and the `dropdownButton`, `dropdownMenu`, `pills`, `search`, `selectedOnly`,
  `selectionBox` objects; charts gain `plotArea.color`, `categoryAxis.outerPadding`, `initialScrollPosition`,
  `autoExpand`; donutChart loses `value.*`, `label.transparency`, `background` (DataArcus writes none of these);
  `debugVisual` leaves the type list.
- `@microsoft/powerbi-report-authoring-cli`: 0.5.0 is still the latest (DataArcus pins it): no bump.
- github.com/microsoft/json-schemas `af7b264` (15 Oct, "Publish SU09 report schemas"): visualConfiguration 2.8.0,
  visualContainer 2.13.0, visualContainerMobileState 2.8.0 (identity changes only: the same structure as 2.7.0 /
  2.12.0 / 2.7.0). DataArcus bundles `8db0a64` (4 Oct), which lacks them; DataArcus writes visualContainer 2.1.0.
  No report, page, definitionProperties or theme schema change. No October (SU10) report schemas published yet.
