## What the code says today (read before planning)
- The old X2 already had no Arabic writer of its own: it ran `planTwin(... into "same")` on the English build held in
  memory. So the port is that wiring onto today's `planTwin`, which since then gained R1 (`langButton`'s plain branch
  with the theme's text colour and container off, `tabInOrder`, `fitTextboxes`, text-box panels off, the per-row field
  names, the matrix line), V1 (`twinPreview`) and M1 (every chart through `report-mirror.js`). Nothing of R1/M1 is
  copied: the bilingual path calls the same functions, so it gets them all.
- What the old build changed that today's code lacks, and where each goes (the block where its cause lives):
  1. `lib/arabic-twin.mjs`: `memoryLoc` + `bytesAt`/`jsonAt` (the original read from memory through the reading block's
     `memorySource`; every `readJson(path.join(loc.dir, ...))` of `readOriginal`, `mobileOf`, `languageCopy`,
     `planTwin`'s `blank`, and now V1's `twinPreview` too, goes through them); `planTwin({ inMemory, textLabels })`
     (labels by the text itself; `textsUnknown`); `languageCopy`'s `.platform` name (the report's own name).
  2. `lib/read-report.mjs`: `canSync(type)` from Microsoft's catalog; `languageCopy` syncs every kind it names, one field.
  3. `langButton`: the first free row of the top quarter when the page has no tabs (today's R1 function, one change).
  4. `server.mjs`: the 4 inputs (`CREATE_REPORT_INPUTS`, REPORT_LOOK; `lookOf` leaves the two maps out), plan problems,
     `exactArtifact`'s bilingual step (`bilingualOf`), `bilingualSaid` (the answer, compact), the plan's data, `writes`,
     create_report's answer (`writeApproved`).
  5. `lib/approval-window.mjs`: `languagesSections` (one function for the twin's EN-AR page and the report's page).
- Deleted for the shared code: nothing of the old X2 had a second mirror or button; the old branch's own approval-page
  copy of the EN-AR sections becomes the twin's function (one). If anything in the port turns out to duplicate R1's or
  M1's code, it is deleted and said in "Results".
- V1: the report's approval page draws `d.preview.pages`, and pairs when `d.preview.pairs` is there (askPage is shared).
  The bilingual plan's preview is `twinPreview(P)` of the plan's own build (the copy's files, read from memory), with the
  English build's check (`previewOf`) kept for its "to check" list.
- Instructions (`lib/agent-text.mjs`): 2,196 of 2,200 characters: no room. The option is said in plan_layout's own
  description (one sentence) and in the `languages` input; the answer says it in one line (`bilingual.sayFirst`).
