## The interfaces (D-1103-11)
- `design-metrics.js` (DAMetrics): in, a saved layout `c` (page, pageW, pageH, preset, kpis, filters, fpos, dir,
  header, sizes), a language (reading direction and label language only), explicit options (logoRatio, tableFields,
  noTime; projectPages' second, panel, maxKpis; fitSlots' dropKinds, headerRows, railItems); out, numbers, boxes and
  slots as new objects. No DOM, storage, clock, browser language or module state (M1). Reads text-measure.js only.
- `design-state.js` (DAState): `upgrade(layout)` and `OLD_LAYOUT_KEYS` at module level (the versioning stays with the
  state); `make({ PRESETS, FONTS, CHART_OPTIONS, BAR_COLORS, DEFAULT_NAME, NAME_MAX })` (the default configuration,
  the engine's) returns `{ SCHEMA, DESIGN_KEYS, LAYOUT_KEYS, fresh, repairState }`; in, a save and an optional
  report callback; out, the repaired design (in place, as before) and one `{ field, given, used, why }` per value not
  used. Reads design-colours.js (clampHex) and design-metrics.js (LAYOUTS, PAGES, RANGE, DEFAULT_PAGE). Pure (M2).
- `design-engine.js` (DAEngine): the facade; its names are exactly the base's (K1, B1), each moved one the module's
  own (F1, F2). Kept: presets and defaults, colours()/roles(), the PNG codec, the theme JSON, readability, the
