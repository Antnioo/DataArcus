## Plan (each fix in the block where its cause lives)
1. **check_report judges each page by its own language** (`assets/js/report-rules.js` `check`, `assets/js/report-a11y.js`
   A11Y_TAB_ORDER, `mcp/lib/check-report.mjs`). check_report works out each page's language: (a) a pair of page buttons
   going to each other's page (the language buttons create_arabic_twin into "same" writes): the page whose button reads
   Arabic letters is the English one, its counterpart the Arabic one; (b) a page reached only from pages of one language
   (a tooltip or drillthrough page) takes that language; (c) the page's own texts (its name, text boxes, then titles);
   (d) else the report's language as before. When the pages hold both, `R.pageDir` (page id -> rtl | ltr) goes to the
   rules: a rule that keys on the direction (RTL_MIRROR, `dir: 'rtl'`; A11Y_TAB_ORDER, new `byDir: true`) runs on each
   direction's pages with that direction. `lang` given by the caller ("ar" or "en") still judges the whole report.
   The answer says `pageLanguages` (counts and how each was told) when the pages differ.
2. **Length alone never makes a text suspicious** (`mcp/lib/model.mjs` `screenWhy`, `mcp/lib/read-report.mjs`
   inventory `flag`). Every SCREEN pattern stays. Decision: a long text keeps being withheld from read_report's answer
   (it is still not shown past 120 characters: answers stay short), and read_report says so in a plain note
   (`longTexts`: how many, and that length is not a sign of an instruction), so the assistant knows why it does not see
   it; check_report never shows texts, so it gets no note.
3. **An approved route for fixes** (`mcp/lib/agent-text.mjs`, `mcp/lib/check-report.mjs`). (a) One sentence,
   `NO_DIRECT_EDITS` in agent-text.mjs: never edit a report's or a model's files yourself (no script, no file tool); to
   change a DataArcus report, ask DataArcus for a plan (the tool and option each finding's fixWith names), show it and
   wait for the approval. It goes into the server's instructions (a new rule, within INSTRUCTIONS_MAX) and into every
   check_report answer (`changes`). (b) check_report tells who built the report (`report.builtBy`): the English and
   Arabic copy (its name ends " (EN-AR)", or its pages have the language buttons), the separate twin (" AR"), a report
   create_report wrote (report.json's generatedBy annotation), else unknown. For a DataArcus report each rule finding
   gets `fixWith`, a key of `fixRoutes`: `arabicCopy` (an Arabic page: create_arabic_twin from the original, into "same"
   or the separate twin as built, a new copy next to the old one once the old is moved: DataArcus never writes over a
   file), `original` (an English page of the copy: fix the original, then make the copy again), `newPlan` (a create_report
   report: plan_layout again on the same model). No new fix tool (see "Decisions I made").
4. **A CI gate on writes**: `mcp/test-0.3.1-write-gate.mjs` (in `npm test`, one result line). It finds every file-writing
   call in `mcp/server.mjs` and `mcp/lib/*.mjs` (the fs calls through any name node:fs is imported as, `io.`/`REAL.` in
   write-io.mjs, and the helpers that wrap them: writeFileNew, writeNew, writeTree, createFile, makeDir, writeAnswers,
   freeFile) counted per file, and fails when a count differs from its list (a new call, or a listed one gone), each
   listed one with why it is safe.
5. **The screen lets plain names with "execute" through** (`mcp/lib/model.mjs` SCREEN): "execute" counts only with an
   object or an imperative after it (execute this / that / it / the / the following / now, "please execute", "execute:"),
   or a code word followed by now or immediately ("execute the script now"). `test-audit-oct.mjs`: "Execute Time", "Avg
   Execute Duration", "Execute Count", "Query Execute Time (ms)" join the not-flagged names, four execute asks join the
   asks (they must stay caught).
