## Reuse
- **design-engine.js: partly yes.** It is one pure UMD file with no I/O, it runs in the browser and in Node, and the website and the MCP use it byte for byte. Missing for black-box use: a written design schema (today only server.mjs:373-375 lists the keys); its own validation and escaping (A2-7); layout rules that live in other blocks (small pages A2-1, slot fitting A2-3, KPI count A2-4); labels for more than two languages (A2-9); and colour roles exported as one function (A2-10).
- **design.mjs: no.** It is MCP-specific: the `repaired`/`fix` record, file writing, the import from the reading block, and layout policy that does not belong there.
- **slots.mjs: no.** It is a shim; delete it once A2-3 is done.

## Bias
- **Measured and recorded:** the theme font limit 8-60 (C2), the card radius, the `minOf` header and rail heights, `kpiInset` (26/17), and PNG-to-visual alignment (calibration backgrounds).
- **Not measured, or measured once:** the 800 threshold and 116 (A2-1, one page size); the 1.5 table share (A2-5, one table, recorded only in WORK.md). Design constants with no Desktop meaning, acceptable as design choices: the 560 title cap, the 90 minimum row height, `generate`'s lightness band, and the 1.6 "weak" contrast threshold.
- **Fixtures:** every re-record in 11ed33a and f9f461d has a cause in `meta.changed`. No golden number was moved without one.
- **Portfolio reports:** nothing in this block names or fits the two portfolio reports. Golden tasks 4 and 5 drive A2-1 and A2-5.
- **Right to left:** mirrored in one place in the engine. The side legend deliberately stays at the right. The writer mirrors ad hoc (B-14, T1).
- **Fonts:** Segoe UI and Tahoma only (A2-11).
